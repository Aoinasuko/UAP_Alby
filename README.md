# Umapyoi Addon Pack : Alby

### 概要
このMODは[Umapyoi](https://www.curseforge.com/minecraft/mc-mods/umapyoi)のアドオンMODです。<br>
新しくオリジナルキャラクターの「アルビィ」のウマ娘魂及びサポートカード(R、SR、SSR)を追加します。<br>

***
### 入手手段
「ウマ娘魂」<br>
 - SR以上のフェードウマ娘魂 + ポピー + 赤色のチューリップでクラフト入手可能

「サポートカード」<br>
 - ガチャで入手 

***
### 能力概要
「ウマ娘魂」<br>
 - 初期から「スピード・賢さ」の上限が高い代わりに、「スタミナ・根性」の上限が低いです
 - 「スピード・賢さ」のトレーニングにボーナスが得られます
 - 固有スキルの「未来の先の先へ」は重複可能で強力な速度上昇効果が得られるものの、効果時間中はHPを消耗していきます
 - 固有スキルの依存能力は「スピード・賢さ」です

「サポートカード」<br>
 - 共通の性質として1人カードとしては強力ですが、体力消費が激しいです 
 - SSRのサポートカードは「未来の先の先へ」の下位互換スキルである「限界突破」を習得できます
